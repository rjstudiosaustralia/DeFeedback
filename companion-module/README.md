# DeFeedback Live Companion module

Bitfocus Companion connection module for the DeFeedback Live Mac host.

For installation and use, see [companion/HELP.md](companion/HELP.md). The module is released with DeFeedback Live and follows the current Bitfocus TypeScript module format.
